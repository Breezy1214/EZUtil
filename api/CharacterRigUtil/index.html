CharacterRigUtil

Helpers for character rigs: finding humanoids, animators and body parts, standing a character on the ground, and working with skinned mesh (Bone based) characters.

Functions​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields

isGroundedState​

</>
CharacterRigUtil.isGroundedState(state: Enum.HumanoidStateType) → boolean

Returns whether a humanoid state counts as standing on the ground: Running, RunningNoPhysics, Landed or None.

findSkinnedMesh​

</>
CharacterRigUtil.findSkinnedMesh(character: Model) → MeshPart?

Returns the MeshPart whose Bone hierarchy poses the character, if the character is built as a skinned mesh rather than as jointed R15 limbs. The PrimaryPart is checked first, then every descendant. Returns nil for a conventional rig, which has no bones.

collectCharacterBones​

</>
CharacterRigUtil.collectCharacterBones(character: Model) → {Bone}

Returns every Bone under character, ordered so a bone always appears after its parent. A character can contain several independent bone trees, including trees rooted under non-MeshParts.
