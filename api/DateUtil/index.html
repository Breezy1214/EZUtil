DateUtil

Helpers for unix timestamps, fixed-length periods (such as daily or weekly resets) and human-readable durations. All timestamps are in seconds.

Types​

DateTimeComponents​

</>

Year: number
Month: number
Day: number
Hour: number
Minute: number
Second: number
Millisecond: number
}

UTC date and time components, as accepted by DateTime.fromUniversalTime.

Functions​

dateTimeComponentsToTimestamp​

</>
DateUtil.dateTimeComponentsToTimestamp(components: DateTimeComponents) → number

Converts UTC date and time components to a unix timestamp in seconds. The milliseconds are kept as a fraction. 

DateUtil.dateTimeComponentsToTimestamp({
	Year = 2024, Month = 1, Day = 1,
	Hour = 0, Minute = 0, Second = 0, Millisecond = 0,
}) -- 1704067200

unix​

</>
DateUtil.unix() → number

Get the current unix timestamp in UTC time. This is the number of seconds since January 1, 1970.

getPeriod​

</>
DateUtil.getPeriod(
timestamp: number,
duration: number,--

The period length in seconds. Must be greater than zero.

offset: number?--

Shifts where periods start, in seconds. Defaults to 0.

) → number

Returns the index of the fixed-length period that contains timestamp, counting from the unix epoch shifted by offset. Useful for daily or weekly resets: two timestamps are in the same period when this returns the same number. 

local today = DateUtil.getPeriod(DateUtil.unix(), DateUtil.SECONDS_PER_DAY)

-- Days that reset at 12:00 UTC instead of midnight
local shiftedDay = DateUtil.getPeriod(DateUtil.unix(), DateUtil.SECONDS_PER_DAY, 12 * 3600)

getPeriodEnd​

</>
DateUtil.getPeriodEnd(
period: number,--

A period index from DateUtil.getPeriod.

duration: number,--

The period length in seconds. Must be greater than zero.

offset: number?--

Defaults to 0.

) → number

Returns the timestamp at which period ends (and the next one starts). Use the same duration and offset that were passed to DateUtil.getPeriod. 

local today = DateUtil.getPeriod(DateUtil.unix(), DateUtil.SECONDS_PER_DAY)
local secondsUntilReset = DateUtil.getPeriodEnd(today, DateUtil.SECONDS_PER_DAY) - DateUtil.unix()

formatDuration​

</>
DateUtil.formatDuration(seconds: number) → string

Formats a duration as hours, minutes and seconds. Negative durations are treated as 0 and fractions of a second are dropped. 

DateUtil.formatDuration(3725) -- "1h 2m 5s"
DateUtil.formatDuration(59) -- "0h 0m 59s"

The DateTime format string to use.

The formatted time in local time.

Example

DateUtil.formatUnix(secondsLeft, "mm:ss") -- 01:20
DateUtil.formatUnix(DateUtil.unix(), "YYYY-MM-DD") -- today's date

timeAgo​

</>
DateUtil.timeAgo(
timestamp: number,
endTimestamp: number?--

The timestamp to compare to. Defaults to the current time.

) → string

Describes how long ago timestamp was, listing every non-zero unit from years down to seconds. Returns "now" for less than a second.

Months and years are averages (30.44 and 365.24 days).

Example

DateUtil.timeAgo(DateUtil.unix() - 80) -- "1 minute 20 seconds ago"
DateUtil.timeAgo(100, 160) -- "1 minute ago"
DateUtil.timeAgo(100, 100) -- "now"

totalTime​

</>
DateUtil.totalTime(
timestamp: number,
endTimestamp: number?,--

The timestamp to compare to. Defaults to the current time.

separator: string?,--

The separator to use between each unit. Defaults to a space.

depth: number?--

The maximum number of units to return.

) → string

Like DateUtil.timeAgo, but without the "ago" suffix, with a custom separator and an optional limit on how many units are listed. Returns "now" for less than a second.

Example

DateUtil.totalTime(0, 3725) -- "1 hour 2 minutes 5 seconds"
DateUtil.totalTime(0, 3725, ", ") -- "1 hour, 2 minutes, 5 seconds"
DateUtil.totalTime(0, 3725, " ", 2) -- "1 hour 2 minutes"
