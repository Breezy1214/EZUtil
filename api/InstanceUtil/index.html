InstanceUtil

Helpers for finding tagged instances, requiring children, welding and turning parts to face a target.

) → Instance?

Returns the nearest ancestor of instance that has the CollectionService tag tag. The instance itself is not checked.

ExpectChild​

</>
InstanceUtil.ExpectChild(

Returns the child of parent named name, or errors with the parent's full path if it does not exist. Does not wait for the child.

lookAt​

</>
InstanceUtil.lookAt(
object: BasePart,--

The part to turn.

target: BasePart,--

The part to face.

rotateOnYAxis: boolean?--

Aim directly at the target instead of staying level.

) → Promise--

Resolves when the tween completes, or rejects if object or target is nil.

Tweens object over 0.2 seconds so it faces target, without moving it.

By default the object stays level and only turns around its Y axis. Pass rotateOnYAxis = true to aim it straight at the target, tilting up or down too. 

InstanceUtil.lookAt(turret, enemy.PrimaryPart):andThen(function()
	fire()
end)
