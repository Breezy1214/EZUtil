LayoutUtil

Keeps ScrollingFrame canvases and their items sized correctly as content and screen size change. Each Fix* function returns a cleanup function that disconnects everything it set up. 

local cleanup = LayoutUtil.FixScrollingCanvas(list.UIListLayout, list, list:FindFirstChildOfClass("UIPadding"))

-- When the UI is destroyed
cleanup()

LayoutUtil.FixScrollingCanvas(

The UIListLayout or UIGridLayout inside the frame.

scrollingFrame: ScrollingFrame,
padding: UIPadding?--

Padding to add around the content.

) → () → ()--

Stops updating the canvas.

Turns off AutomaticCanvasSize and keeps CanvasSize fitted to the layout's content plus any padding, never smaller than the visible window. Only the axes the frame scrolls on are sized; the other axis is set to 0.

Updates are batched to the next Heartbeat after a child is added or removed, the content or window size changes, the scrolling direction changes, or the padding changes.

) → () → ()--

Disconnects and destroys the size constraints. The layout's padding is not restored.

Locks each item and the layout's padding to the height they were authored with, resolved against the scrolling frame's visible height. Scale heights then stay relative to the viewport instead of growing with the canvas. Each item gets a UISizeConstraint, and the layout's Padding is rewritten in pixels whenever the window resizes.

FixLayout​

This item only works when running on the client. Client
</>
LayoutUtil.FixLayout(
layout: UIGridStyleLayout,
scrollingFrame: ScrollingFrame,
itemAspectRatio: (number | UDim2)?,
padding: UIPadding?
) → () → ()--

Disconnects and destroys the constraints this call created.

Adds a UIAspectRatioConstraint to each visible item in the scrolling frame and keeps the vertical canvas fitted to the content plus any top and bottom padding. Items added later are constrained as they arrive. Items that already have a UIAspectRatioConstraint of their own are left alone.

itemAspectRatio decides the ratio:

  • a positive number is used for every item;
  • a UDim2 is converted to a ratio once, against the frame's canvas size minus padding;
  • any other number (0, negative or infinite) gives each item the ratio of its own Size against the frame's size, re-applied whenever the frame resizes;
  • nil adds no constraints and only fixes the canvas.
