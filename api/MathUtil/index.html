shortenNumber​

</>
MathUtil.shortenNumber(
number: number | string,
minimumTiers: number?--

The minimum number of tiers to shorten. Defaults to 1.

) → string

Shortens a large number to a readable format. Useful for displaying large numbers that don't require exact precision. Common use cases are for displaying XP, money in leaderboards, damage etc.

Shortened numbers keep one decimal place, truncated rather than rounded, so a value never reads as more than it is: 999,999 shortens to 999.9K instead of rolling up to 1,000K.

Example:

MathUtil.shortenNumber(1000) -- 1K
MathUtil.shortenNumber(1200) -- 1.2K
MathUtil.shortenNumber(999999) -- 999.9K
MathUtil.shortenNumber(1000000) -- 1M
MathUtil.shortenNumber(1000000000) -- 1B
MathUtil.shortenNumber(1000000000000) -- 1T
MathUtil.shortenNumber(1000000000000000) -- 1Q

minimumTiers is useful for when you want to shorten a number but only if it's at least a certain tier. For example, to only shorten numbers of 1,000,000 or more: 

MathUtil.shortenNumber(250000, 2) -- 250,000
MathUtil.shortenNumber(1000000, 2) -- 1M

A tier is the amount of commas in a number. For example, 1,000,000 has 2 tiers and 1,000 has 1 tier.

Tier list and their abbreviations:

  • 1,000 = K
  • 1,000,000 = M
  • 1,000,000,000 = B
  • 1,000,000,000,000 = T
  • 1,000,000,000,000,000 = Q

randomInDisc​

</>
MathUtil.randomInDisc(radius: number) → Vector3

Returns a random flat offset (Y = 0) inside a disc of the given radius. Points are spread evenly over the disc's area rather than bunched at its centre. 

local spawnPosition = center + MathUtil.randomInDisc(20)
