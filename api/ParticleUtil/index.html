ParticleUtil

Helpers for particle effects: waiting for effect templates, emitting one-shot bursts, and switching effects off so their particles fade out before cleanup.

Burst templates are Attachments whose ParticleEmitters use these attributes:

  • EmitCount (number): how many particles to emit. Emitters without it are skipped.
  • EmitDelay (number, optional): seconds to wait before emitting.

burst​

</>
ParticleUtil.burst(
template: Attachment,
cframe: CFrame--

The world CFrame to emit from.

) → ()

Clones template into workspace.Terrain at cframe and emits every ParticleEmitter that has an EmitCount attribute, after its optional EmitDelay. The clone is removed once the last particle can have expired. 

local template = ParticleUtil.waitForTemplate("Explosion", ReplicatedStorage.Effects)
if template then
	ParticleUtil.burst(template, CFrame.new(position))
end
