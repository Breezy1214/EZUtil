PlayerUtil

Helpers for players and their characters: humanoids, animators and animations, character measurements, group ranks and permission levels, and hiding player UI.

Properties​

userLevel​

</>
PlayerUtil.userLevel: {[string]: number}

The permission levels returned by PlayerUtil.getUserLevel, from lowest to highest: normal (0), premium (1), VIP (2), moderator (3), superuser (4) and creator (5). 

if PlayerUtil.getUserLevel(player) >= PlayerUtil.userLevel.moderator then
	-- allow moderation commands
end

Functions​

ensureAnimator​

</>
PlayerUtil.ensureAnimator(character: Model) → Animator?--

nil if the character has neither an Animator nor a Humanoid.

Returns the Animator under the character's Humanoid (or directly under the character). If there is none and the character has a Humanoid, a new Animator is created under it.

loadAnimation​

</>
PlayerUtil.loadAnimation(
janitor: Janitor,
character: Model,
animationId: string
) → AnimationTrack?--

nil if the character has no Animator.

Loads an animation onto the character's existing Animator with Action4 priority. The janitor stops the track (with a one second fade) and destroys it when cleaned up. This does not create an Animator; see PlayerUtil.ensureAnimator.

Example:

local track = PlayerUtil.loadAnimation(janitor, character, "rbxassetid://1234567890")
if track then
	track:Play()
end

getGroupRank​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
PlayerUtil.getGroupRank(

groupId: number
) → number

Gets a player's rank in a group. Results are cached for 60 seconds, and a failed request returns 0.

Example:

PlayerUtil.getGroupRank(player, 1) -- 255

isCreator​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
PlayerUtil.isCreator(player: Player) → boolean

Checks if a player created the game: the owning user, or a rank 255 member of the owning group.

Example:

PlayerUtil.isCreator(player) -- true

getUserLevel​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
PlayerUtil.getUserLevel(player: Player) → number

Gets a player's permission level, one of the PlayerUtil.userLevel values:

  • creator if PlayerUtil.isCreator is true;
  • in a group-owned game: superuser for rank 253 and above, moderator for rank 99 exactly, and VIP for ranks below 10 (including players outside the group);
  • otherwise premium for Premium members, or normal.

Example:

PlayerUtil.getUserLevel(player) -- 0

getHumanoid​

</>
PlayerUtil.getHumanoid(object: Instance?) → Humanoid?

Gets the Humanoid of a Player's character, a character Model, or a Humanoid itself. Warns if object is not an Instance.

Example:

PlayerUtil.getHumanoid(player) -- Humanoid
PlayerUtil.getHumanoid(workspace.Zombie) -- Humanoid

getCharacterHeight​

</>
PlayerUtil.getCharacterHeight(character: Model) → number?--

nil if the character has no PrimaryPart.

Returns the height of the character's bounding box.

isAlive​

</>
PlayerUtil.isAlive(obj: Instance) → boolean

Checks if a Player, character Model or Humanoid has a Humanoid with health above 0. Returns false if no Humanoid is found.

Example:

PlayerUtil.isAlive(player) -- true
PlayerUtil.isAlive(workspace.Zombie) -- false
PlayerUtil.isAlive(workspace.Part) -- false

</>

Checks if a Player, character Model or Humanoid has a Humanoid.

Example:

PlayerUtil.hasHumanoid(player) -- true
PlayerUtil.hasHumanoid(workspace.Zombie) -- true

getPlayerFromInstance​

</>
PlayerUtil.getPlayerFromInstance(
instance: Instance?--

Anything other than a BasePart returns nil.

) → Player?

Gets the Player whose character contains a BasePart, by walking up its ancestors until one holds a Humanoid. Also available as PlayerUtil.getPlayerFromPart.

Example:

hitbox.Touched:Connect(function(part)
	local player = PlayerUtil.getPlayerFromInstance(part)
end)

getPositiontAtFeet​

</>
PlayerUtil.getPositiontAtFeet(character: Model) → Vector3

Gets the position at the feet of a character: its PrimaryPart's position, lowered by half the height of the character's bounding box. Errors if the character has no PrimaryPart.

Example:

local effectPosition = PlayerUtil.getPositiontAtFeet(player.Character)

getPlayerFromPart​

</>
PlayerUtil.getPlayerFromPart(instance: Instance?) → Player?

Alias of PlayerUtil.getPlayerFromInstance.

getCharacterInformation​

</>
PlayerUtil.getCharacterInformation(player: Player) → (
Model?,
Humanoid?,
BasePart?
)

Returns a player's character, its Humanoid and its HumanoidRootPart. Returns nothing if the player has no character. 

local character, humanoid, rootPart = PlayerUtil.getCharacterInformation(player)

disableOtherUi​

This item only works when running on the client. ClientThis is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
PlayerUtil.disableOtherUi(
value: boolean,--

true to hide, false to restore.

exception: string?--

The name of a ScreenGui to leave alone.

) → ()

Hides or restores every ScreenGui in the local player's PlayerGui, except the one named exception and any whose name contains "Topbar". Hiding remembers each ScreenGui's Enabled state so restoring puts it back. 

PlayerUtil.disableOtherUi(true, "ShopGui") -- hide everything but the shop
PlayerUtil.disableOtherUi(false) -- restore
