ProjectileUtil

Ballistic projectile helpers: solve the launch velocity that reaches a target in a given time, move a part along that arc with optional hits and bounces, and draw the arc as an aim preview.

Gravity defaults to workspace.Gravity (read when the module is first required), pointing down. 

local controller = ProjectileUtil.launch({
	part = rock,
	origin = hand.Position,
	target = mouseHit,
	duration = 0.8,
	raycastParams = params,
	onHit = function(position, normal)
		rock:Destroy()
	end,
})

launch​

</>
ProjectileUtil.launch(config: ProjectileConfig) → ProjectileController

Anchors config.part and moves it along the ballistic arc from config.origin to config.target every Heartbeat.

Without raycastParams the part flies the full arc and onHit is called with the final position and a nil normal. With raycastParams, each frame's movement is raycast: on a hit the part either bounces (reflecting its velocity, scaled by bounceDamping, while bounces remain) or stops and calls onHit with the hit position and surface normal.

createAimBeam​

</>
ProjectileUtil.createAimBeam(config: AimBeamConfig) → AimBeam

Draws the ballistic arc from config.origin to config.target with a single curved Beam, held by an invisible, anchored, non-colliding part parented to config.parent. Call Update to redraw it as the aim changes. 

local beam = ProjectileUtil.createAimBeam({
	origin = hand.Position,
	target = mouseHit,
	duration = 0.8,
	parent = workspace,
})

RunService.RenderStepped:Connect(function()
	beam:Update(hand.Position, mouseHit, 0.8)
end)
