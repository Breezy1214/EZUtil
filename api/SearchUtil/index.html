SearchUtil

Helpers for searching Instance trees and nested tables: counting and collecting parts, walking up ancestors, depth-limited searches, and checking that named children exist.

Functions​

getPartCount​

</>
SearchUtil.getPartCount(instance: Instance?) → number

Counts the BaseParts among the descendants of the given instance. Warns and returns 0 if instance is nil.

Example:

SearchUtil.getPartCount(workspace.NPC) -- 5

Example:

getAncestor​

</>
SearchUtil.getAncestor(
child: Instance,
condition: string | (obj: Instance) → boolean
) → Instance?

Walks up from child, starting with child itself, and returns the first instance that matches condition. A string matches by name; a function matches when it returns true. Returns nil if nothing matches.

Example 1:

local map = SearchUtil.getAncestor(part, "Map")

Example 2:

detector.Touched:Connect(function(part: BasePart)
	local bot: Model? = SearchUtil.getAncestor(part, function(instance: Instance)
		return instance:HasTag("NPC")
	end)

	if bot ~= nil then
		print("NPC bot touched the detector")
	end
end)

find​

</>
SearchUtil.find(
node: Instance | {[any]: any},
condition: any | (obj: any) → boolean,--

A predicate, or a key to look for.

maxDepth: number?,--

How many levels to search. Defaults to 1.

_depth: number?--

Internal: tracks the current depth. Leave as nil.

) → any

Searches the children of node (an Instance's children, or a table's values) level by level and returns the first match. The search continues until maxDepth is reached, a match is found, or there is nothing left to search. Returns nil when no match is found.

By default maxDepth is 1, so only the direct children of node are searched.

condition can be:

  • a function, called with each child; the first child it returns true for is returned;
  • a key, checked on each child: for Instance children, the child's own child with that name is returned; for table children, the table that has that key is returned.

Function condition example:

local player: Player? = SearchUtil.find(game.Players, function(player: Player)
	return player.Name == "Player1"
end)

Key example:

-- The first Humanoid inside a direct child of workspace
local humanoid = SearchUtil.find(workspace, "Humanoid")

Table example:

local NPCs = {
	{ Name = "NPC1", Health = 0 },
	{ Name = "NPC2", Health = 20 },
	{ Name = "NPC3", Health = 0 },
}

local firstAliveNPC = SearchUtil.find(NPCs, function(NPC)
	return NPC.Health > 0
end) -- { Name = "NPC2", Health = 20 }

exists​

</>
SearchUtil.exists(
node: Instance | {[string]: any},
children: (string | {string})?
) → boolean

Checks if the given node has children (for an Instance) or keys (for a table) with the given names. A single name can be passed as a string, or several names as a table. Returns false if children is nil.

Instance node example:

SearchUtil.exists(
	character,
	{ "Head", "UpperTorso", "LeftUpperArm", "RightUpperArm" }
) -- true

SearchUtil.exists(character, "Head") -- true

Table node example:

local config = { Damage = 10, Range = 20 }

SearchUtil.exists(config, { "Damage", "Range" }) -- true
SearchUtil.exists(config, "Cooldown") -- false
