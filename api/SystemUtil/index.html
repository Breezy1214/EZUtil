SystemUtil

General runtime helpers: frame-driven timers, disconnecting connections, cached product info and platform checks.

Functions​

timeout​

</>
SystemUtil.timeout(
delay: number,--

Seconds to wait.

callback: (number) → ()--

Receives the seconds elapsed since the timeout started.

) → ()

Calls callback once at least delay seconds have passed, checking every RunService.Stepped. Does not yield.

Example:

SystemUtil.timeout(1, function()
	print("One second later")
end)

interval​

</>
SystemUtil.interval(
interval: number,--

Seconds between calls.

callback: (
number,
number
) → boolean?--

Receives the seconds elapsed since the interval started and the last frame's delta time.

) → RBXScriptConnection

Calls callback every interval seconds, checking every RunService.Stepped. Each call runs in its own thread. Return false from the callback, or call :Disconnect() on the returned connection, to stop the interval.

Example:

local ticks = 0
SystemUtil.interval(1, function()
	ticks += 1
	return ticks < 10 -- stop after 10 ticks
end)

inTable​

</>
SystemUtil.inTable(
searchTable: {[any]: any},
target: any
) → boolean

Checks if a value is in a table.

Example:

SystemUtil.inTable({ 1, 2, 3 }, 2) -- true
SystemUtil.inTable({ 1, 2, 3 }, 4) -- false
SystemUtil.inTable({ Part, 2, 3, Part2 = true }, Part) -- true

disconnect​

</>
SystemUtil.disconnect(connection: RBXScriptConnection? | {RBXScriptConnection?}) → ()

Disconnects a connection, or every connection in an array. Nil values and non-connections in the array are skipped. 

SystemUtil.disconnect(connection)
SystemUtil.disconnect({ connectionA, connectionB })

getProductInfo​

This is a yielding function. When called, it will pause the Lua thread that called the function until a result is ready to be returned, without interrupting other scripts. Yields
</>
SystemUtil.getProductInfo(
productId: number,
infoType: Enum.InfoType?--

Defaults to Enum.InfoType.Asset.

) → {[any]: any}?

Returns MarketplaceService:GetProductInfo for a product. Successful results are cached for the lifetime of the server or client, and failed requests return nil instead of erroring. 

local info = SystemUtil.getProductInfo(productId, Enum.InfoType.Product)
if info then
	print(info.Name, info.PriceInRobux)
end

isMobile​

This item only works when running on the client. Client
</>
SystemUtil.isMobile() → boolean

Returns whether the player is on a touch device: touch is enabled and neither a keyboard nor a mouse is. In Studio only TouchEnabled is checked, so the device emulator counts as mobile.

isConsole​

This item only works when running on the client. Client
</>
SystemUtil.isConsole() → boolean

Returns whether a gamepad is enabled. This is also true on PC or mobile while a controller is connected.
