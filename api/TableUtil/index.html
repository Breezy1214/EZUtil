TableUtil

Table and string helpers: flipping, mapping, filtering and merging tables, reading paths through nested tables or Instances, splitting and joining strings, and random picks.

Functions​

flip​

</>
TableUtil.flip(
source: {[any]: any},--

The table you want to flip

mergeDuplicates: boolean?--

Merge key duplicates into a table instead of overwriting them.

) → {[any]: any}

Flips the table's keys with its values. If mergeDuplicates is true, All values will be stored in a table at the key's index, instead of overwriting them.

Example:

TableUtil.flip({ a = 1, b = 2 }) -- { [1] = "a", [2] = "b" }
TableUtil.flip({ a = 1, b = 2 }, true) -- { [1] = { "a" }, [2] = { "b" } }

-- Use case: finding all keys with the same value
local newTable = TableUtil.flip({ a = 1, b = 2, c = 2 }, true) -- { [1] = { "a" }, [2] = { "b", "c" } }
print(#newTable[2]) -- 2

split​

</>
TableUtil.split(
text: string | number?,
delimiter: string?,
trimTrailingDelimiter: boolean?,
trim: boolean?--

Trim whitespace from each chunk

) → {string}

Splits a string into a table of strings using a delimiter. If delimiter is not provided, it defaults to a space.

Setting trimTrailingDelimiter to false will result in an empty string at the end of the table if the text ends with the delimiter

Setting trim to false will result in whitespace not being trimmed from each chunk

Example:

TableUtil.split("Hello, world!") -- { "Hello,", "world!" }
TableUtil.split("Hello, world!", ", ") -- { "Hello", "world!" }
TableUtil.split("Hello, world!", ",", nil, false) -- { "Hello", " world!" } -- no whitespace is trimmed
TableUtil.split("Hello, world!,", ",", false) -- { "Hello", "world!", "" } -- trailing delimiter is included

TableUtil.split("path/to/file", "/") -- { "path", "to", "file" }
TableUtil.split("path/to/file/", "/") -- { "path", "to", "file" } -- trailing delimiter is trimmed

extend​

</>
TableUtil.extend(
arg1: boolean | {[any]: any},--

The target table, or true for deep mode

arg2: {[any]: any},--

The first table to merge in, or the target table in deep mode

...: {[any]: any}--

The tables you want to merge into the target table

) → {[any]: any}

Extends a table with one or more tables, in order, and returns it. The target table is modified in place.

Example:

TableUtil.extend({ a = 1 }, { b = 2 }, { c = 3 }) -- { a = 1, b = 2, c = 3 }
TableUtil.extend({ a = 1 }, { a = 2 }, { a = 3 }) -- { a = 3 } -- Last argument overwrites previous arguments
TableUtil.extend({ a = 1 }, { a = 2 }, { a = 3 }, true) -- Error: Argument #3 must be a table

Config override example:

local function getDefaultConfig()
	return {
		health = 100
	}
end

local buffConfig = {
	health = 150,
	speed = 1.5
}

local playerConfig: { [any]: any } = TableUtil.extend(getDefaultConfig(), buffConfig) -- { health = 150, speed = 1.5 }

Pass true as the first argument for deep mode, in which case the target table is the second argument. Note that nested tables are currently assigned by reference rather than merged key by key.
