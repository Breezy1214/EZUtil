VfxUtil

Plays VFX templates: BaseParts holding ParticleEmitters, Lights and other parts. Emitters are configured with attributes:

  • EmitCount (number): particles to emit. Defaults to the emitter's Rate.
  • EmitDelay (number): seconds to wait before starting. Defaults to 0.
  • EmitDuration (number): when above 0, the emitter is enabled for this many seconds instead of emitting EmitCount once. Falls back to the template part's own EmitDuration attribute, then 0.

play​

VfxUtil.play(
template: BasePart,
cframe: CFrame,
parent: Instance?--

Defaults to workspace.

) → BasePart--

The playing clone.

Plays a one-shot copy of template at cframe. The clone and every part inside it are anchored and made non-colliding, each ParticleEmitter is played according to its attributes, Lights fade to zero brightness over 0.35 seconds, and the clone is destroyed once its longest emitter has finished. 

VfxUtil.play(effects.Slam, VfxUtil.uprightAt(effects.Slam, hitPosition))

attach​

</>
VfxUtil.attach(
template: BasePart,
part: BasePart--

The part to weld the effect to.

) → () → ()--

Stops the effect and cleans it up.

Welds a copy of template to part and enables all of its emitters, returning the stop function. Stopping switches the emitters and lights off, which lets the particles already in flight fade out on their own before the clone is cleaned up. Calling the stop function more than once does nothing. 

local stop = VfxUtil.attach(effects.Aura, character.HumanoidRootPart)
task.wait(5)
stop()
